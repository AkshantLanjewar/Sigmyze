## Introduction
This file contains all the base classes needed in order to store and edit quanta projects on the ASP.net server leveraging MongoDB.

## QuantaProjectCacheId
This is the document that creates an association between a process id and a quanta project.

### Definition
```cs
public class QuantaProjectCacheId
{
    public string? Id { get; set; }
    public string? OrganizationId { get; set; }
    public string? ProjectId { get; set; }
    public string? ProcessId { get; set; }
}
```

**Fields**
- `Id` (this is the mongodb id for the document)
- `OrganizationId` (this is the id of the organization the drive belongs too)
- `ProjectId` (this is the id of the associated quanta project)
- `ProcessId` (this is the assigned process id for the rust service to use)

## QuantaRepositoryDefinition
This is the document that stores all of the project editor data related to a specific quanta dataset on the MongoDB database.

### Definition
```cs
public class QuantaRepositoryDefinition
{
    public string? Id { get; set; }
    public string? ProjectId { get; set; }
    public string? ProjectName { get; set; }
    public string? OrganizationId { get; set; }
    public QuantaProjectData? ProjectData { get; set; }
}
```

**Fields**
- `Id` (this is the mongodb id for the document)
- `ProjectId` (this is the id of the associated quanta project)
- `ProjectName` (name for the quanta project, used for display purposes)
- `OrganizationId` (this is the id of the organization the drive belongs too)
- `ProjectData` (this is the actual editor [data](#quantaprojectdata) for the project)

**Methods**
```cs
public bool Validate()
```
This is the function that validates whether or not this is a valid document.

## QuantaProjectData
This class contains all of the UI/UX data that needs to be backed up to the MongoDB database.

### Definition
```cs
public class QuantaProjectData
{
    public string? DatasetName { get; set; }
    public string? DatasetId { get; set; }
    public string? DatasetDescription { get; set; }
    public List<QuantaFile>? Files { get; set; }
    public QuantaDataStore? Store { get; set; }
    public List<QuantaSchemas>? DatasetSchema { get; set; }  
}
```

**Fields**
- `DatasetName` (name of the dataset, for display purposes)
- `DatasetId` (the display id for the dataset)
- `DatasetDescription` (the description for the dataset, user provided)
- `Files` (these are the ["files"](#quantafile) within the project)
- `Store` ([stores](#quantadatastore) all of the project data from the project, such as node editor configs, and selector setups)
- `DatasetSchema` (list of all the used [schemas](#quantaschemas) within the quanta project)

## QuantaFile
This is the model definition for a file ("front for a project, quanta, lunar etc...") within a users drive.

### Definition
```cs
public class QuantaFile
{
    public string? Name { get; set; }
    public string? Type { get; set; }
    public string? Id { get; set; }
}
```

**Fields**
- `Name` (this is the name of the project, used for display purposes)
- `Type` (this is the type of project, either quanta or lunar)
- `Id` (this is the project id, assigned at creation)

## QuantaDataStore
This is the model that contains all of the core editor data needed for a quanta project, such as selectors, categories, text strings, and node editor data.

### Definition
```cs
public class QuantaDataStore
{
    public List<QuantaSelector>? Selectors { get; set; }
    public List<QuantaEditorProject>? EditorProjects { get; set; }
    public QuantaCategorization? Categorization { get; set; }
    public Dictionary<string, string>? TextStore { get; set; }
}
```

**Fields**
- `Selectors` (these are the custom ux [selectors](#quantaselector) used to select an indicator from the dataset)
- `EditorProjects` (these are the data for the node editor files to fetch and update the dataset)
- `Categorization` (these are the user defined [categories](#quantacategorization) for the dataset)
- `TextStore` (any text strings generated by users in the editor are stored here in key value form)

## QuantaCategorization
This is the definition for the user defined categories in the quanta project`

### Definition
```cs
public class QuantaCategorization
{
    public string? FileName { get; set; }
    public string? MapsTo { get; set; }
    public List<string>? Categories { get; set; }
    public Dictionary<string, List<string>>? CategoriesMap { get; set; }
}
```

**Fields**
- `FileName` (categories are uploaded as a JSON file, this is the name of the file that was uploaded)
- `MapsTo` (this is the indicator key that the categories map to)
- `Categories` (this is a string list of all the categories uploaded to the dataset)
- `CategoriesMap` (this maps a single category to a list of indicator key values in order to effectively query indicators)

## QuantaSelector
This is the defintiion for a selector for a quanta project. A selector is a custom piece of UX code that is run, that can query the dataset in order to help the user select an indicator in the most effective way possible for a specific dataset.

### Definition
```cs
public class QuantaSelector
{
    public string? SelectorId { get; set; }
    public string? SelectorName { get; set; }
    public string? SelectorDescription { get; set; }
    public QuantaSelectorCode? SelectorCode { get; set; }
    public QuantaSelectorPipeline? SelectorPipeline { get; set; }
}
```

**Fields**
- `SelectorId` (this is the id for the selector, assigned at creation)
- `SelectorName` (name of the selector, used for editor display purposes)
- `SelectorDescription` (user defined description for the selector, used for editor display purposes)
- `SelectorCode` (this is the [code](#quantaselectorcode) that powers the selector that runs in an iFrame)
- `SelectorPipeline` (this is the [definition](#quantaselectorpipeline) for pipelining any additional dataset data into the selector at launch)

## QuantaSelectorPipeline
This is the definition for the object that configures the data that is pipelined into a selector for a quanta dataset.

### Definition
```cs
public class QuantaSelectorPipeline
{
    public List<QuantaPipelinedObjects>? PipelinedObjects { get; set; }
    public List<QuantaPipelineAnalysis>? PipelineAnalyses { get; set; }
    public Dictionary<string, string>? PipelineLinks { get; set; }
}
```

**Fields**
- `PipelinedObjects` (these are the [objects](#quantapipelinedobjects) that configure the data that gets pipelined into the selector)
- `PipelineAnalyses` (these are the [results](#quantapipelineanalysis) of the pipeline operation being completed)
- `PipelineLinks` (these link the pipeline objects to a dataset key value in order to pull the data)

## QuantaPipelinedObjects
This is the definition for the object that adds pipelined data into a selector.

### Definition
```cs
public class QuantaPipelinedObjects
{
    public string? PipelineId { get; set; }
    public string? PipelineType { get; set; }
    public string? PipelineName { get; set; }
    public string? DatasetId { get; set; }
    public bool? Reservable { get; set; }
}
```

## QuantaPipelineAnalysis
This is the result of the quanta pipeline operation after the data has been pulled.

### Definition
```cs
public class QuantaPipelineAnalysis
{
    public string? ObjectId { get; set; }
    public string? ObjectType { get; set; }
    public bool? IsArray { get; set; }
    public string? StringValue { get; set; }
    public List<string>? StringArray { get; set; }
    public int? DateValue { get; set; }
    public List<int>? DateArray { get; set; }
}
```

**Fields**
- `ObjectId` (this is the id of the object returned from the operation)
- `ObjectType` (type returned, either string or date)
- `IsArray` (whether or not the data returned was an array)
- `StringValue` (this is the string value for the object if it is not an array)
- `StringArray` (this is the value for the object if it is a string and an array)
- `DateValue` (this is the value for the object if it is a date and not an array)
- `DateArray` (this is the value for the object if it is a date and an array)

## QuantaSelectorCode
This is the object that stores the code that is run in the iFrame sandbox in order to display and connect the selector to the wider quanta platform.

### Definition
```cs
public class QuantaSelectorCode
{
    public string? ContainerId { get; set; }
    public string? SchemaId { get; set; }
    public string? SchemaName { get; set; }
    public string? SourceCode { get; set; }
    public Dictionary<string, string>? SelectorLinks { get; set; }
    public List<QuantaSchemaItem>? SchemaItems { get; set; }
    public string? DefaultValue { get; set; }
}
```

**Fields**
- `ContainerId` (this is the id of the code that was uploaded, generated field)
- `SchemaId` (this is the id of the schema that defines this selector's output)
- `SchemaName` (the name of the schema for this selectors output, used for display purposes)
- `SourceCode` (the compiled source code that can be run in an iFrame container)
- `SelectorLinks` (these are the links between the schema and the dataset key values in order to match the output)
- `SchemaItems` (these are the schema definition [nodes](#quantaschemaitem) that define the output for the selector)
- `DefaultValue` (default output for the selector)

## QuantaSchemaItem
This is a node that defines an item within a schema for a quanta schema.

### Definition
```cs
public class QuantaSchemaItem
{
    public string? Name { get; set; }
    public string? Type { get; set; }
}
```

**Fields**
- `Name` (the name for the schema node, display use only)
- `Type` (the type for the node, currently supports strings and dates)

## QuantaSchemas
This is the central repository for most schemas that are defined in the quanta project, as node editors and other components leverage them as well.

### Definition
```cs
public class QuantaSchemas
{
    public string? SchemaId { get; set; }
    public QuantaSchema? Schema { get; set; }
}
```

**Fields**
- `SchemaId` (this is the id of the schema, used to query it from the list)
- `Schema` (this is the actual schema that is being stored (list of nodes))
