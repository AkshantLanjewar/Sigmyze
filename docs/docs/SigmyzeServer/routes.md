# Routes

The routes for the server are split up into theese main subroutes:
- `api/v1/polis` : [PolisController](./Controllers/polis-controller.md)
- `api/v1/maps` : [MapsController](./Controllers/maps-controller.md)
- `api/v1/datasets` : [DatasetsController](./Controllers/datasets-controller.md)
- `api/v1/auth` : [AuthController](./Controllers/auth-controller.md)
- `api/v1/organizations` : [OrganizationsController](./Controllers/organizations.md)
- `api/v1/drive` : [DriveController](./Controllers/drive-controller.md)

Each route has an associated subroute which can be explored in the Controllers portion of the documentation
