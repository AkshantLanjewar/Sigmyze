# Routes

The routes for the server are split up into theese main subroutes:
- `api/v1/polis`
- `api/v1/maps`
- `api/v1/datasets`
- `api/v1/auth`
- `api/v1/organizations`
- `api/v1/drive`

Each route has an associated subroute which can be explored in the Controllers portion of the documentation
